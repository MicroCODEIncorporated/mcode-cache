DESCRIPTION: ------------ This module implements the MicroCODE's Common JavaScript functions for data caching. NOTE: o 'key' in this code refers to the Application Key or File Path. o 'cacheKey' in this code refers to a fully qualified cache Key. o 'cacheKeys' are made from 'key' values by the 'cacheMakeKey()' method, which formats the 'key' into a cache Key with a prefix based on the current Namespace. o '_cache*()' are private methods that are not exposed to the caller, these expect 'cacheKey' values, not 'key' values. - application 'key' format : - 'cacheKey' format Examples: key: '/backend/components/app/tool/tool.template.htmx' cacheKey: 'GM-GPS-eMITS-UI:backend:components:app:tool:tool.template.htmx' key: 'myKey' cacheKey: 'MicroCODE:myKey' REFERENCES: ----------- 1.
